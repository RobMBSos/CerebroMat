# Local fonts

Baloo 2 and Nunito WOFF2 subsets copied unchanged from the production site on 21 October 2026. Their font-face declarations, weights, Unicode ranges and fallback metrics are preserved in app/fonts.css. The Latin subsets are preloaded; other subsets load only when needed.

Both families use the SIL Open Font License; license files are included. Upstream: https://github.com/google/fonts/tree/main/ofl/baloo2 and https://github.com/google/fonts/tree/main/ofl/nunito.

These assets eliminate build-time Google Fonts requests.
